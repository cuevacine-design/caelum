# Caelum Storytelling — sitio

Base de la web de Caelum Storytelling (productora audiovisual), publicada con GitHub Pages.

- `index.html` — inicio: logo, presentación, fotos y servicios.
- `privacidad.html` — política de privacidad del sitio y de la herramienta interna que conecta las cuentas de Google del estudio. Es la página que pide Google para publicar esa herramienta.
- `img/` — logo, lema, ícono y fotos del sitio anterior (Google Sites, 2023).
- `letra/` — Lexend, con su licencia SIL Open Font License 1.1 (`OFL.txt`). Se sirve desde acá: el sitio no carga nada de terceros.

Si se cambia la dirección del sitio, hay que actualizarla también en Google Cloud › Google Auth Platform › Información de la marca.
